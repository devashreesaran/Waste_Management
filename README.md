This project implements a hybrid AI-based waste classification system.

- YOLOv8 → Detects waste objects
- MobileNetV2 → Classifies fine-grained waste categories
- Streamlit → Web interface

## Installation

Clone the repository

git clone https://github.com/devashreesaran/Waste_Management.git

cd Waste_Management

Install dependencies

pip install -r Requirements_YOLOv8.txt
pip install -r Requirements_MobileNetV2.txt

Run the application

streamlit run app.py
